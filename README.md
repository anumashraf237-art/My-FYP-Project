# 🩺 Doctor Appointment Hub

A comprehensive web-based healthcare management system built with Python Flask. This project aims to streamline the process of booking doctor appointments, managing patient and doctor profiles, and providing AI-powered symptom checking.

## 🚀 Features
*   **Patient Portal:** Search for doctors, book appointments, and view medical history.
*   **Doctor Portal:** Manage schedules, view upcoming appointments, and update patient records.
*   **AI Symptom Checker:** An intelligent feature to help users understand potential health issues before consulting a doctor.
*   **Admin Dashboard:** Manage users, doctors, and system-wide settings.
*   **Secure Authentication:** Role-based login system for Patients, Doctors, and Admins.

## 🛠️ Tech Stack
*   **Backend:** Python (Flask)
*   **Database:** MySQL
*   **Frontend:** HTML, CSS, JavaScript, Jinja2 Templates
*   **APIs:** OpenAI API (for Symptom Checker)
